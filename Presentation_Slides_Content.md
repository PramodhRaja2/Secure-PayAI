## Slide 4: System Architecture Flow (How It Works)
**Header:** From Click to Settlement
**Visual Suggestion:** A clean flowchart.
**Steps:**
1. **Initiation:** User enters trade details.
2. **Pathfinding:** Backend AI Optimizer Engine queries providers (e.g., TransferWise, Revolut SIM) for live FX rates.
3. **Risk Scoring:** System evaluates session metadata and assigns a Probability of Fraud.
4. **Biometric Validation:** "Fraud Simulation" locks execution if the risk score exceeds 60.
5. **Settlement:** Transaction committed immutably to the SQL Audit Ledger.
